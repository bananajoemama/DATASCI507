# DATASCI507
Repo for DATASCI 507 homeworks and projects

DATA507 is a course on Python, and how to use it for data science in analytics in today's world. We learn the fundamentals of the language, Python syntax, libraries and functions we can implement, and lots more! We also do a data science project at the end of the semester. This repo contains my homework so far, as well as future projects for the class. 

The hw folder contains the homeworks, and once we're assigned projects I'll add a "proj" folder to keep those as well.
